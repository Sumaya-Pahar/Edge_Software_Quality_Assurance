# Edge_Software_Quality_Assurance

## Course Overview
This repository contains assignments, reports, and practical works completed for the **Software Quality Assurance (SQA)** course under the **EDGE (Enhancing Digital Government and Economy)** program.  
The course focuses on software testing methodologies, quality assurance processes, validation techniques, and test case design for modern web applications.

Through this course, I learned how to analyze software systems, identify defects, validate website quality, and design effective test cases for real-world applications.
